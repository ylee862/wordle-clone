# Wordle Clone

A clone of the popular word-guessing game Wordle! This application replicates the core functionality and user interface of the original Wordle, providing players with an interactive and fun way to test their word-guessing skills.

## Project Overview

The Wordle Clone allows users to guess a hidden word within a limited number of attempts.

Users input a guess, and the application compares it with the correct answer.

The colors of the tiles change based on the accuracy of the guess:
- Green: Correct letter in the correct position.
- Yellow: Correct letter in the wrong position.
- Gray: Incorrect letter.

This project was developed using HTML5, CSS, and JavaScript, focusing on creating a visually similar user interface and replicating the game's logic.

## Features

### Implemented:
#### Interactive Gameplay:
Users can type their guesses and get instant feedback via color-coded tiles.

#### Accurate Answer Validation:
Compares the user's guess to the correct word and updates the UI accordingly.

#### Dynamic UI Updates:
Colors change dynamically based on the input accuracy, mimicking the original Wordle experience.

### Upcoming Improvements:
- Implement animations for a smoother and more engaging experience.
- Store game statistics (e.g., number of games played, wins, and streaks).
- Add dynamic UI for the keyboard.
- Adding a feature so the word changes everyday.
